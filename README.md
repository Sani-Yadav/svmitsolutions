# SVM IT Solutions — Official Website

> **Technology That Moves Your Business Forward**  
> Modern, high-performance web platform built with React 18, Vite, and modular CSS architecture.

---

## 🚀 Features

- **Modern & Responsive UI**: Pixel-perfect layout tailored for desktop, tablet, and mobile devices.
- **Modular Component Architecture**: Decoupled components, sections, and structured data layers.
- **Fast Client-Side Routing**: Hash-based routing for smooth navigation and dedicated service detail views (`#service/:slug`).
- **Free Consultation Modal**: Interactive modal with keyboard accessibility (Escape, focus trap) and direct email integration.
- **WhatsApp Integration**: Floating quick-connect button with automated scroll visibility.
- **SEO & Performance Optimized**: Sub-second initial load with Vite build optimization and semantic HTML structure.

---

## 🛠️ Tech Stack

- **Frontend Library**: [React 18](https://react.dev/)
- **Build Tool**: [Vite 5](https://vitejs.dev/)
- **Styling**: Vanilla CSS (CSS3 custom variables, clamp typography, glassmorphism)
- **Deployment**: Static Web Hosting / Vercel / Netlify / GitHub Pages

## 💻 Getting Started

### Prerequisites

- Node.js (version 18+ recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Sani-Yadav/svmitsolutions.git
   cd svmitsolutions
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Configure environment variables (optional):
   ```bash
   cp .env.example .env
   ```

4. Start development server:
   ```bash
   npm run dev
   ```

5. Build for production:
   ```bash
   npm run build
   ```
